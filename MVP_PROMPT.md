# MVP Prompt: Herbal Products Website & WhatsApp Integration

## Project Overview

Create an automated online forms application integrated with WhatsApp for a herbal products website that provides medical consultation services, membership management, and product sales.

## Core Features

### 1. WhatsApp Integration
- Automated form submission via WhatsApp
- Real-time notifications and responses
- Two-way communication channel for consultations

### 2. Healer Online Consultation Form
A comprehensive medical consultation form with the following fields:

**Personal Information:**
- Age (dropdown/input: 18-80 years)
- Contact information

**Medical History (Last 5 Years):**
- Brief medical history text field
- Infection details:
  - What was the infection? (text field)
  - Was it chronic? (Yes/No radio buttons or checkbox)
- Current condition or other (text area)
- Disclose any other treatment (text area)

**Form Requirements:**
- Live/real-time page
- Form validation
- Secure data submission
- Mobile-responsive design

### 3. Benefits Section
Display the following benefits prominently on the website:

- **Free Medical Advice (Consultation)**: Highlight free consultation services
- **Medical Emergencies Online**: 24/7 emergency consultation availability
- **Join the Website**: Membership registration option
- **Registration Fee**: Clear pricing for membership
- **Training of Users**: User training resources and materials
- **Cyber Security Tightening**: Security features and compliance information
- **Targeting 50% of the Population**: Marketing messaging

### 4. Membership System
- **Join Option**: Registration with Credit Card payment integration
- **Registration Fee**: Payment processing for membership
- **Member Dashboard**: Access to exclusive content and services
- **Secure Payment Gateway**: Credit card processing

### 5. Product Categories
Organize products into the following categories:

- **Renal** (Kidney-related herbal products)
- **Prostate Cancer** (Prostate cancer-related herbal products)

Each category should have:
- Product listings
- Product details pages
- Add to cart functionality

### 6. Pricing Structure
- **Family Kit**: $30
- **Individual**: $10

Display pricing clearly on product pages and checkout.

## Administrative & Technical Requirements

### 2. Demo Account

### 3. Records and Reports System
Comprehensive record-keeping system with:

- **Patient Records**: Store consultation form submissions

- **Treatment Options**: Document treatment plans
- **Testimonials**:

  - Include before/after photos where applicable
